Installation Guide:

## 1. Install Python:
First, download Python from the [official website](https://www.python.org/downloads/) and follow the installation instructions.

## 2. Install Required Libraries:
Once Python is installed, open your command prompt or terminal and run the following commands to install the necessary libraries:

```
pip install mysql-connector-python
pip install py-cord 
pip install psutil 
pip install python-dotenv
```

By following these steps, you'll be able to run the bot on your own system, enjoy!
